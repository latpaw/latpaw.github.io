怎么玩

🧊

六面迷宫

魔方每个面都是一片迷宫。通道会跨过棱边接到相邻面，走到边缘就自动翻到另一个面上。

🔄

转动面

点面心的铜把手，或按「转这一面」，整面顺时针转 90°。站在上面会被一起转走。要让棱边两侧的通道口对上。

🎥

自由旋转

按住拖动可以从任意角度转动魔方，滚轮或双指缩放。左侧六个面按钮可一键把某个面转到镜头前。

👆

移动

点击地面自动寻路，也可以用 WASD 或方向键，触屏还有方向盘。

🗺

展开图

右上角是六个面的十字展开图，一眼看清所有通道、钥匙、机关和自己的位置。

🔑

钥匙与门

走到钥匙上自动捡起，同色的门自动打开。钥匙常常藏在别的面上。

⚙️

齿轮与拉杆

齿轮黄色缺口对准白指针、指示灯变绿就对了；艰难难度里齿轮会带动邻居。拉杆升起木桥补上缺口。

💎

水晶与星星

第一次点水晶会演示顺序，照着点即可，点错不扣分。每关藏 3 颗星星；艰难难度有发条能量，走一步或转一次面少一格。

传送门明细

每一对门开在互为对面的两个面上。「必需」＝出口被墙封死，只能靠这对门过去。

和孩子在电视上一起玩

先开「双人合作」+「电视模式」，再按下面任一方式把画面送到电视

推荐 1

🔌 HDMI 直连电视

电脑用 USB-C / HDMI 线接电视，电视遥控器切到对应 HDMI 输入。Mac 在「系统设置 → 显示器」选镜像，浏览器按 ⌃⌘F 全屏。

延迟最低、画质最好，手柄蓝牙连电脑。想认真玩就选这个。

推荐 2

🎮 掌机 / 迷你主机接电视

Steam Deck、ROG Ally 或客厅迷你 PC 用底座 / HDMI 接电视，浏览器打开本文件夹的 index.html，手柄即插即用。

最接近游戏主机的体验，不用每次搬电脑。

推荐 3

📡 AirPlay 镜像

Apple TV 或支持 AirPlay 2 的电视：Mac 控制中心 → 屏幕镜像 → 选电视。iPhone / iPad 也可以直接镜像。

无线最省事，但有约 0.1 秒延迟。本作是回合式解谜，完全能接受。

推荐 4

📺 Chromecast 投放

Chrome 右上 ⋮ → 投放 → 来源选「投放整个桌面」，不要选「投放标签页」。

投标签页会走视频压缩，3D 画面会糊；投桌面明显更清楚。

不推荐

🌐 电视自带浏览器

把文件夹拷到 U 盘或局域网共享，用电视浏览器打开。多数电视浏览器 WebGL 支持很弱。

能开也常常掉帧或黑屏，只适合应急。

走不通

🕹️ Switch 直接玩

零售版 Switch 没有通用浏览器，网页版跑不了。要上 Switch 得走任天堂授权 SDK 重新打包。

想在客厅玩，上面四种都比这条路快得多。

🎮 手柄怎么连

Mac「系统设置 → 蓝牙」里配对 Xbox 无线手柄、PS5 DualSense 或 PS4 手柄。连上后要在游戏画面里按一下任意键，浏览器才会把它交给游戏——这是浏览器的规定，不是没连上。

两个手柄分别对应 P1 / P2。没有手柄也能双人：P1 用 WASD + F 转面 + G 操作，P2 用方向键 + Enter 转面 + Shift 操作。

电视模式会放大字幕并留出安全边距，避免电视过扫描把边缘裁掉
